# Regression & Classification — MPG Dataset & MNIST

**Hellenic Open University | MSc Data Science & Machine Learning | 2024–2026**

---

## Overview  
This project contains two end-to-end machine learning workflows implemented in Python using scikit-learn, covering both regression and classification tasks.

---

## Problem 1 — Predicting Car Fuel Efficiency (Regression)

- **Dataset:** MPG dataset (seaborn)  
- **Goal:** Predict miles per gallon (fuel efficiency) based on vehicle attributes  
- **Techniques:** Exploratory Data Analysis, feature correlation analysis, log transformations  
- **Model:** Linear Regression within a scikit-learn Pipeline with StandardScaler  
- **Evaluation:** R², MAE, MAPE, MSE, 10-fold cross-validation  

---

## Problem 2 — MNIST Digit Classification (KNN)

- **Dataset:** MNIST handwritten digits  
- **Goal:** Binary classification (odd vs even digits)  
- **Model:** K-Nearest Neighbors (KNN) with hyperparameter tuning (k = 3, 5, 7)  
- **Evaluation:** Accuracy, Precision, Recall, Confusion Matrix, ROC-AUC  

---

## Tools & Libraries

Python · NumPy · pandas · scikit-learn · matplotlib · seaborn
