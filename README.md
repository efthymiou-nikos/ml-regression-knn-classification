# Regression & Classification — MPG Dataset & MNIST

**Hellenic Open University | MSc Data Science & Machine Learning | 2024-26**

---

## Overview
Two machine learning problems solved end-to-end using Python and scikit-learn.

## Problem 1 — Predicting Car Fuel Efficiency (Regression)
- Dataset: MPG dataset (seaborn)
- Goal: Predict miles per gallon based on car attributes
- Techniques: Exploratory Data Analysis, feature correlation, log transforms
- Model: Linear Regression inside a scikit-learn Pipeline with StandardScaler
- Evaluation: R², MAE, MAPE, MSE, 10-fold cross-validation

## Problem 2 — MNIST Digit Classification (KNN)
- Dataset: MNIST handwritten digits
- Goal: Binary classification — odd vs even digits
- Model: K-Nearest Neighbours with grid search (K = 3, 5, 7)
- Evaluation: Accuracy, Precision, Recall, Confusion Matrix, ROC-AUC

## Tools & Libraries
Python · scikit-learn · pandas · matplotlib · seaborn · numpy
